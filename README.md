## Ejercicios de Python – Fundamentos de Data Analytics

### Descripción del proyecto

Este proyecto recoge una colección de ejercicios prácticos en Python orientados a consolidar las bases de programación necesarias para el análisis de datos.

Se han trabajado diferentes problemas enfocados en lógica, manipulación de datos y estructuración de código, siguiendo buenas prácticas de programación.
